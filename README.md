# Rescue Mission — AI Coursework Project

## Overview
This project explores route planning in a grid environment with obstacles and multiple victim locations.

## Technologies
- Python
- NumPy
- Matplotlib
- Breadth-First Search (BFS)
- Genetic Algorithm

## How It Works
- Represents the environment as a 10×10 grid.
- Uses BFS to calculate paths and distances.
- Uses a Genetic Algorithm to search for a suitable order for visiting 5 victim locations.
- Visualizes the resulting route using Matplotlib.
